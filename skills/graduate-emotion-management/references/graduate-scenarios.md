# Graduate Student Scenario Taxonomy

Use this file to classify a user's graduate-school distress before choosing an intervention. Always identify:

- Object: who or what the emotion is organized around.
- Event: the concrete trigger, not a broad theme.
- Emotion: likely primary emotions, secondary emotions, and body/behavior signals.
- Scope cue: signs that the request needs professional, medical, legal, or emergency help instead of this self-help skill.
- Response focus: the first safe direction for support.

Do not force the user into one category. If several scenarios apply, name the top one or two and say the situation may have multiple layers.

## Classification Protocol

1. Extract the user's words for object, event, and emotion.
2. If emotion is unclear, infer gently and ask whether it fits.
3. Separate event facts from interpretations. Example: "导师说这版不行" is an event; "我废了" is an interpretation.
4. Check risk before ordinary support.
5. Choose one response focus: stabilize, clarify, decompose, communicate, plan, restore, or refer.

Use this short internal schema:

```text
Object:
Event:
Primary emotion:
Secondary emotion:
Body/behavior signal:
Risk level:
Need:
First response focus:
```

## Object Map

| Object | Includes | Typical hidden need |
|---|---|---|
| Self | ability, identity, motivation, body, sleep, self-worth | competence, rest, acceptance, direction |
| Supervisor | criticism, control, neglect, unclear expectations, conflict | clarity, respect, safety, autonomy |
| Lab or cohort | peers, senior students, collaborators, lab culture | belonging, fairness, boundaries |
| Research project | experiments, data, code, theory, fieldwork, feasibility | predictability, progress, problem solving |
| Paper and degree | submission, rejection, thesis, defense, graduation | recognition, closure, time security |
| Institution | rules, funding, assessment, accommodation, leave, reporting | procedural clarity, protection, rights |
| Family or intimate relationship | expectations, money, marriage, caregiving, conflict | understanding, support, separation |
| Career future | academia, industry, unemployment, age pressure, identity | agency, options, realistic planning |
| Body and health | sleep, panic, illness, medication, exhaustion | safety, care, recovery |

## Common Emotion Vocabulary

When the user only says "崩溃", "麻了", "烦", "受不了", or "没意思", offer emotion labels gently:

| User wording | Possible emotions | Ask gently |
|---|---|---|
| 崩溃 | Panic, overwhelm, helplessness, grief | "更像是害怕、委屈、愤怒，还是太累了？" |
| 麻了 | Numbness, dissociation-like shutdown, exhaustion | "是没有感觉，还是感觉太多所以关机了？" |
| 烦死了 | Irritation, anger, overload, loss of control | "这个烦更靠近愤怒，还是被压得喘不过气？" |
| 我废了 | Shame, despair, identity threat | "这句话像是自我评价，不一定是事实。发生的具体事件是什么？" |
| 不想干了 | Exhaustion, grief, trapped feeling, desire to stop | "这是想休息、想换方向，还是想停止眼前这项任务？" |
| 没意思 | Loss of meaning, low mood, burnout | "这个没意思更像是对课题失去意义，还是整个人太耗尽了？" |
| 我受不了了 | Overwhelm, panic, desperation | "现在更像是身体绷得很紧，还是脑子已经转不动了？" |

## Output Shape

When useful, briefly show the scenario map to the user:

```text
我先帮你拆一下：
对象：导师/论文/自己
事件：今天组会上被否定，且 deadline 很近
情绪：羞耻、害怕、委屈，可能还有愤怒
现在优先：先稳住，再把下一步缩小到一个可执行动作
```

Do not show a long table unless the user asks for a full analysis.
