## 自适应支持规则

- 支持回复不设置字符、句子、段落、支持层数或对话周期配额。
- 短披露仍需具体回应已知事件和情绪逻辑，但不得为了显得充分而编造背景或扩大解释。
- 详细披露、重要追述及“多陪我说几句”的请求，应获得与其分量相称的回应；是否充分以新增理解和用户感受为准，不以长度达标为准。
- 每个段落都应增加具体识别、情绪逻辑、负担或意义、压力缓解、陪伴或选择；同义安慰、理论展示、情绪清单和建议不得用于填充篇幅。
- 用户要求简短、文字负荷过高或只需要一个即时动作时，回复可以更短，但仍须保持具体和温和。

## 结论

0.4.2 当前实现以功能质量而非长度配额组织支持：短披露保持具体但承认未知，详细披露保留其情绪中心，用户不想继续说时允许停留。每次回复前会核对当前对话中的已确认身份、活跃问题、偏好、方法反馈和未完成事项；跨对话连续性通过用户明确同意的本地档案实现，不宣称模型天然拥有永久记忆。
