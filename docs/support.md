# 硕博生情绪支持：帮助与联系

发布者显示名：Zoey（爱读书的zoey）  
支持渠道：https://github.com/Zoey-lovereading/graduate-emotion-support/issues
发布平台：GitHub  
可用范围：全球，但受承载平台实际可用地区、当地法律和本插件使用条款限制。

## 可以反馈什么

- 插件未按说明触发或回复明显异常。
- 回复越过非临床自助边界。
- 运动建议忽略用户明确说明的疼痛或身体限制。
- 出现隐私、版权、商标或许可问题。
- 发现测试未覆盖的硕博生情绪支持场景。

## 请不要发送

- 完整对话记录或未经删减的聊天截图。
- 真实姓名、学号、身份证号、电话号码或精确住址。
- 病历、处方、诊断证明或其他医疗文件原件。
- 导师、同学、患者、实验参与者或家人的可识别信息。
- 账号密码、访问令牌或其他凭据。

反馈时只需说明插件版本、问题发生的大致场景、期望行为和已经删除身份信息的最小必要片段。

## 服务边界

GitHub Issues 是公开渠道，请不要提交任何敏感个人信息。该支持渠道不是心理咨询、医疗、危机干预或紧急服务，也不保证即时回复。存在现实安全危险时，请联系身边可信人员和所在地适当的紧急或专业服务。
