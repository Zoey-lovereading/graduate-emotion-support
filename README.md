# 硕博生情绪支持

[English](README_EN.md) | 简体中文

面向 18 岁及以上硕士生、博士生和科研人员的低风险、非临床情绪支持插件。它优先理解具体经历和情绪，再由用户选择是否进入情绪调节、科研问题拆解、抗挫复盘、运动辅助或学业恢复。

## 主要能力

- 导师批评、实验失败、拒稿、倦怠、自我怀疑和科研停滞后的具体陪伴。
- 把反馈处理、恢复选择、方法迭代、求助和边界保护视为可训练的科研元能力，但不美化痛苦。
- 不按固定字数、支持层数或对话轮数组织回答。
- 用户明确同意后，可建立可查看、更正和删除的本地连续性档案。
- 用户授权后才进入问题解决、运动或学业计划；漏做不补，不制造任务欠账。

## 使用方式

当前推荐显式调用：

```text
$graduate-emotion-management 导师今天当着组里批评了我，请先陪我把这件事聊清楚，不要马上给建议。
```

自然语言隐式触发受平台调度影响，当前测试中运动模块隐式触发仍不稳定，不作为承诺能力。

## 安全边界

本插件不是心理咨询、心理治疗、诊断、医疗、危机干预或紧急服务。它不提供药物方案、临床判断、地区或学校危机资源匹配。当前自伤、他伤、急性医疗危险或其他超出低风险自助范围的情况，应立即联系现实中的可信任人员和适当的当地紧急或专业服务。

## 数据与连续性

当前版本没有开发者自建服务器、账户、分析或广告组件。可选连续性档案只有在用户确认保存内容和私人位置后才创建，不默认保存完整对话或每次情绪变化，也不会自动发送给开发者。
